NETLIFY DEPLOYMENT
1. Unzip the folder.
2. Open your GitHub repository.
3. Upload all files and the assets folder into the repository root.
4. Commit the changes.
5. Netlify will automatically redeploy if the repository is connected.

NOMINATION FORM
The nomination form is configured for Netlify Forms. After deployment, submissions appear under Forms inside your Netlify dashboard.
